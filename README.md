# Banco de dados. Projeto final Fic

Este repositório contém o desenvolvimento completo do banco de dados relacional Karatefic, projetado para gerenciar as operações de uma federação de karatê, incluindo o controle de atletas, graduações, academias e a organização de lutas e campeonatos.

Modelagem e Desenvolvimento: BR Modelos - Visual Paradigm - MySQL Workbench.
